# Kontakwa Style - GitHub Pages

## Cara menggunakan

1. Buat repository baru di GitHub.
2. Upload `index.html` dan folder `images`.
3. Ganti `images/profil.jpg` dengan foto profil yang diinginkan.
4. Buka `index.html`, lalu ubah nomor:
   - `6281234567890` untuk WhatsApp.
5. Masuk ke **Settings → Pages**.
6. Pada **Build and deployment**, pilih:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
7. Simpan dan tunggu GitHub Pages aktif.

URL biasanya:
`https://USERNAME.github.io/NAMA-REPOSITORY/`
